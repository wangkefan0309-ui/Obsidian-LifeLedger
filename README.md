# Obsidian LifeLedger

## Demo

<video src="https://cdn.jsdelivr.net/gh/wangkefan0309-ui/Obsidian-LifeLedger@main/assets/LifeLedger-Demo.mp4" controls width="100%" poster="assets/lifeledger-demo-cover.svg"></video>

[Watch the LifeLedger demo video](https://cdn.jsdelivr.net/gh/wangkefan0309-ui/Obsidian-LifeLedger@main/assets/LifeLedger-Demo.mp4)

**LifeLedger** 是一个面向 Obsidian 的本地化个人财务管理插件，旨在帮助用户在自己的知识库中完成日常记账、资产管理、支出分析与财务复盘。

它不是一个单纯的记账工具，而是希望把“财务记录”纳入个人知识管理系统，让每一笔收入、支出、资产变化都可以被长期保存、回顾和分析。

## 项目简介

LifeLedger 是一个 Obsidian 插件，主要用于在 Obsidian 内部完成个人财务记录与分析。

插件围绕“本地数据”“长期记录”“可视化复盘”三个核心目标设计：

- **本地数据存储**：财务数据保存在用户自己的 Obsidian 仓库中，便于长期管理和备份。
- **统一记账入口**：用户可以在插件主界面完成收入、支出等记录。
- **可视化仪表盘**：通过图表和数据卡片展示月度收支、资产构成、支出分类等信息。
- **个人系统融合**：适合作为 Obsidian 人生管理系统中的财务模块使用。

## 核心功能

### 1. 仪表盘概览

插件提供财务仪表盘，用于快速查看当前财务状态。

仪表盘中可以展示：

- 本月收入
- 本月支出
- 本月结余
- 平均每日支出
- 年度收入统计
- 年度支出统计
- 年度结余情况
- 资产总览
- 资产构成
- 主要支出项目
- 最近记账记录

仪表盘的目标不是堆砌数据，而是帮助用户快速回答几个问题：

- 我这个月花了多少钱？
- 钱主要花在哪里？
- 我的资产结构是否健康？
- 最近有没有明显的异常支出？
- 本年度的财务趋势如何？

### 2. 收入与支出记录

用户可以通过插件界面添加收入和支出记录。

每条记录通常包含：

- 类型：收入或支出
- 分类：如饮食、交通、购物、学习、娱乐、工资等
- 金额：本次收入或支出的金额
- 日期：记录发生时间
- 备注：对该笔记录的补充说明

通过这种方式，用户可以把日常消费转化为可复盘的数据。

### 3. 分类管理

LifeLedger 支持按照不同类别管理收入和支出。

常见支出分类示例：

- 饮食
- 交通
- 购物
- 学习
- 娱乐
- 生活用品
- 医疗健康
- 人情往来
- 其他

常见收入分类示例：

- 工资
- 奖学金
- 兼职
- 投资收益
- 家庭支持
- 其他收入

分类的意义在于让用户不仅知道“花了多少钱”，还知道“钱流向了哪里”。

### 4. 资产管理

插件支持记录和展示个人资产情况。

可记录的资产类型包括但不限于：

- 现金
- 银行卡余额
- 支付宝
- 微信余额
- 基金
- 股票
- 数字资产
- 其他资产

通过资产构成图，用户可以直观看到自己的资产分布情况。

### 5. 流血项目分析

LifeLedger 关注高频、持续、容易被忽视的支出项目。

所谓“流血项目”，指的是那些单次金额可能不大，但长期累计后会明显影响财务状况的支出，例如：

- 外卖
- 奶茶
- 打车
- 游戏充值
- 冲动购物
- 会员订阅
- 频繁小额消费

这个功能的目标不是制造消费焦虑，而是帮助用户发现真正影响财务状态的支出习惯。

### 6. 月度记录与年度概览

插件支持按照月份和年份查看财务情况。

月度维度适合观察：

- 本月收入
- 本月支出
- 本月结余
- 分类支出排名
- 最近消费记录

年度维度适合观察：

- 全年收入趋势
- 全年支出趋势
- 年度结余变化
- 不同月份之间的消费差异

通过月度和年度两个维度，用户可以同时进行短期控制和长期复盘。

### 7. 本地 Markdown 数据存储

LifeLedger 的设计理念之一是尽量让数据保存在本地，而不是依赖第三方服务器。

财务记录可以按照一定规则保存在 Obsidian 仓库中的文件夹内，例如：

```text
LifeLedger/
├── 2026/
│   ├── 01/
│   │   ├── 2026-01-01.md
│   │   ├── 2026-01-02.md
│   │   └── ...
│   ├── 02/
│   └── ...
└── assets.md
```

这种方式有几个优点：

- 数据属于用户自己
- 可以跟随 Obsidian 仓库一起备份
- 可以配合 Git、网盘、移动硬盘等方式长期保存
- 不依赖单一平台
- 方便未来迁移和二次开发

## 使用场景

LifeLedger 适合以下用户：

- 希望在 Obsidian 中建立个人财务系统的人
- 希望长期记录收入、支出和资产变化的人
- 不想把所有财务数据交给第三方记账 App 的人
- 重视数据本地化、可控性和长期保存的人
- 已经在 Obsidian 中搭建人生管理系统的人
- 希望通过财务数据复盘生活习惯的人

## 安装方式
### 方法一：手动安装

1. 目前插件可以通过手动方式安装。
2. 下载本项目代码。
3. 构建插件文件。
4. 将构建后的插件文件夹放入 Obsidian 仓库的插件目录：
```
你的Obsidian仓库/.obsidian/plugins/obsidian-lifeledger/
```
5. 打开 Obsidian。
```
设置 → 第三方插件 → 已安装插件
```
6. 找到 LifeLedger 并启用。

### 方法二：开发模式安装

如果你希望在本地进行开发和调试，可以按照下面的方式运行项目。

#### 开发环境

本项目基于 Obsidian 插件开发环境构建，通常需要：

1. Node.js
2. npm
3. Obsidian
4. Git
5. VS Code 或其他代码编辑器

建议使用较新的 Node.js LTS 版本。

#### 本地开发

- 克隆项目：
``` 
git clone https://github.com/wangkefan0309-ui/Obsidian-LifeLedger.git
```
- 进入项目目录：
```
cd Obsidian-LifeLedger
```
- 安装依赖：
```
npm install
```
- 启动开发模式：
```
npm run dev
```
- 构建生产版本：
```
npm run build
```
构建完成后，将必要文件复制到 Obsidian 插件目录中。

通常需要的文件包括：
```
main.js
manifest.json
styles.css
```
具体文件以项目实际构建结果为准。

#### 推荐目录结构

项目目录可能类似于：
```

│   ├── main.ts
│   ├── views/
│   ├── components/

│   └── styles/
```

如果项目结构发生调整，请以实际代码为准。

## 数据安全说明

LifeLedger 关注本地化和长期保存，但用户仍然需要注意数据备份。

建议至少保留两份以上备份，例如：

- Obsidian 本地仓库一份
- 移动硬盘或 U 盘一份
- 云盘同步一份
- Git 私有仓库一份

财务数据具有一定隐私性，如果使用 GitHub 备份，请注意：

- 不要把包含真实财务信息的仓库公开。
- 不要上传敏感个人数据。
- 如果使用 GitHub，建议使用私有仓库。
- 如果数据文件中包含个人资产、账户、交易备注等内容，应谨慎处理。

## 设计理念

LifeLedger 的核心理念是：

> 财务管理不是为了限制生活，而是为了看清生活。

很多记账工具只解决“记录问题”，但 LifeLedger 更关注“复盘问题”。

一笔消费本身并不重要，真正重要的是长期记录之后呈现出来的趋势：

- 哪些消费是必要的？
- 哪些消费是冲动的？
- 哪些支出在持续侵蚀现金流？
- 哪些收入来源值得继续加强？
- 当前资产结构是否足够稳健？
- 自己的生活方式是否和长期目标一致？

LifeLedger 希望把财务数据变成一种自我认知工具。

它不是为了制造消费焦虑，也不是为了要求用户压抑正常生活，而是帮助用户更清楚地理解自己的金钱流向、生活习惯和长期目标之间的关系。

当收入、支出、资产和复盘被统一放入 Obsidian 这样的个人知识系统中，财务管理就不再只是孤立的数字记录，而会成为人生管理系统的一部分。

## 注意事项

在使用 LifeLedger 前，请注意：

1. 本插件目前主要面向个人使用场景。
2. 插件不提供金融投资建议。
3. 插件中的统计结果仅基于用户输入的数据。
4. 如果用户没有持续、准确记录，统计结果可能存在偏差。
5. 请定期备份自己的 Obsidian 仓库。
6. 请谨慎处理真实财务数据和个人隐私信息。
